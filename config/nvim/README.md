# NVim-HP

Personal Neovim setup for:

- Python
- Rust
- Web (Vue, Quasar, JS/TS)
- Data Science / HPC workflows

## Features

- LSP (mason + lspconfig)
- Autocomplete (nvim-cmp)
- Treesitter
- File explorer (neo-tree)
- Fuzzy finder (telescope)
- Statusline (lualine)
- Git integration (gitsigns)
- Commenting (Comment.nvim)
- Autopairs
- Surround editing
- Keymaps with which-key

## Installation

```bash
git clone <repo> ~/.config/nvim
nvim

## Requirements

- Neovim >= 0.9 (you are using 0.11.5)
- Git
- Node.js (for some LSPs)
- ripgrep (for Telescope live grep)
- fd (optional, improves file search)
